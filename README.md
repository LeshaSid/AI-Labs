# AI-Labs

Репозиторий с лабораторными работами по искусственному интеллекту и машинному обучению.

## Описание проекта

Этот проект содержит набор лабораторных работ, охватывающих различные области искусственного интеллекта, включая:
- Нейронные сети и глубокое обучение
- Компьютерное зрение (CV)
- Обработку естественного языка (NLP)
- Трансформеры и современные архитектуры

## Структура проекта

```
AI-Labs/
├── Lab1/                           # Лабораторная работа 1

├── Lab3/                           # Лабораторная работа 3
├── Lab4/                           # Лабораторная работа 4
├── Lab5/                           # Лабораторная работа 5
├── Lab6/                           # Лабораторная работа 6

├── Реферат Трансформеры.docx       # Реферат о трансформерах

```

## Технологический стек

- **Язык:** Python
- **Основные библиотеки:**
  - PyTorch (глубокое обучение)
  - NumPy, Pandas (работа с данными)
  - Scikit-learn (машинное обучение)
  - Marimo (интерактивные ноутбуки)

## Установка

### Требования
- Python 3.8 или выше
- pip или uv package manager

### Способ 1: Использование uv (рекомендуется)

```bash
# Клонировать репозиторий
git clone https://github.com/LeshaSid/AI-Labs.git
cd AI-Labs

# Установить зависимости
uv sync
```

### Способ 2: Использование pip

```bash
# Клонировать репозиторий
git clone https://github.com/LeshaSid/AI-Labs.git
cd AI-Labs

# Установить зависимости из pyproject.toml
pip install -e .
```

## Использование

### Запуск интерактивных ноутбуков

```bash
# Запустить Marimo приложение
marimo edit LabX/notebook.py
```

### Работа с моделями

Проект включает предобученные веса модели CNN для компьютерного зрения:

```python
import torch

# Загрузить предобученную модель
model_weights = torch.load('cv_cnn_model_weights.pth')
# Используйте веса в вашей модели
```

## Конфигурация проекта

Проект использует `pyproject.toml` для управления зависимостями и конфигурацией. Основные инструменты:

- **Package Manager:** uv (быстрый менеджер пакетов для Python)
- **Python Version:** Указана в `.python-version`
- **Dependencies:** Зафиксированы в `uv.lock`
