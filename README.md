# AI-Labs: Лабораторные работы по искусственному интеллекту и методам машинного обучения

Данный репозиторий содержит комплекс лабораторных работ, охватывающих основные разделы машинного обучения и искусственного интеллекта. Работы выполнены с использованием Python и современных библиотек для анализа данных, классического машинного обучения, ансамблевых методов и глубокого обучения.

## Лабораторные работы

### Лабораторная работа 1: Предобработка данных
- Загрузка датасета `Automobile.csv` (характеристики автомобилей).
- Обработка пропусков (заполнение медианой).
- Нормализация числовых признаков методом MinMaxScaler.
- Кодирование категориальных признаков (one-hot encoding).
- Сохранение обработанных данных в `processed_automobile.csv`.

### Лабораторная работа 2: Регрессия и классификация
- Линейная и полиномиальная регрессия с регуляризацией (Ridge).
- Классификация с помощью логистической регрессии.
- Визуализация матрицы ошибок и ROC-кривой.
- Оценка качества моделей (RMSE, точность, полнота, F1-мера).

### Лабораторная работа 3: Деревья решений
- Реализация деревьев решений для регрессии и классификации.
- Использование критериев: энтропия (ID3) и Джини (CART).
- Визуализация структуры дерева.
- Оценка качества и анализ переобучения.

### Лабораторная работа 4: Ансамблевые методы
- Случайный лес (Random Forest) с оценкой Out-of-Bag (OOB) и подбором случайных признаков.
- Бустинг: AdaBoost и градиентный бустинг (Gradient Boosting).
- Сравнение ROC-кривых и метрик классификации.

### Лабораторная работа 5: Многослойный перцептрон
- Генерация синтетических данных (бинарная классификация с шумом).
- Построение и обучение нейронной сети с одним скрытым слоем (PyTorch).
- Визуализация процесса обучения (график потерь).
- Оценка точности и матрица ошибок.

### Лабораторная работа 6: Свёрточная нейронная сеть (CNN) для распознавания жестов
- Построение архитектуры CNN с двумя свёрточными слоями, батч-нормализацией и полносвязными слоями.
- Аугментация данных для улучшения обобщения.
- Обучение на наборе изображений жестов рук (20 классов).
- Сохранение весов и инференс модели на новых изображениях с предобработкой (градации серого, центрирование, размытие).

## Требования

- Python 3.14 или выше
- Установка зависимостей через `uv` или `pip`

Список основных библиотек:
- `marimo` — интерактивные блокноты (опционально)
- `pandas`, `numpy` — обработка данных
- `scikit-learn` — классические ML-алгоритмы
- `matplotlib`, `seaborn` — визуализация
- `torch`, `torchvision` — глубокое обучение

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <url-репозитория>
   cd AI-Labs
   ```

2. Установите зависимости. Для работы с `uv`:
   ```bash
   uv sync
   ```
   Или с помощью `pip`:
   ```bash
   pip install -r requirements.txt
   ```

3. Запуск лабораторных работ:
   Каждая лабораторная работа представляет собой Python-скрипт (например, `Lab1/lab1.py`). Запуск выполняется стандартно:
   ```bash
   python Lab1/lab1.py
   ```
   Для работ, использующих `marimo`, можно запустить интерактивный режим:
   ```bash
   marimo edit Lab1/lab1.py
   ```
